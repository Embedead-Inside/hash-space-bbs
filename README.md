# hash-space-bbs

[![License: MIT-0](https://img.shields.io/badge/License-MIT--0-blue.svg)](https://spdx.org/licenses/MIT-0.html)

データベース不要で動く、軽量なルーム制の簡易掲示板です。PHP ファイル1つ（`bbs.php`）を置くだけで動作します。

「合言葉」を決めて入室すると、同じ合言葉を知っている人だけが同じ掲示板に書き込めます。部屋は合言葉の MD5 で決まり、URL の `room=<MD5>` で直接入ることもできます。投稿は約12日で自動的に消えます。

## 特長

- **PHP 1ファイル**で完結（HTML / CSS / JavaScript も同梱）。外部ライブラリ・データベース・追加の PHP 拡張は不要
- **合言葉の MD5 が部屋の ID。** MD5 をファイル名にして、OS の一時ディレクトリに JSON で保存。URL の `room=<MD5>` で部屋に直接入れる
- **排他制御（`flock`）**で、同時書き込みによるデータ破損を防止
- **投稿は自動消滅**（約12.1日）。古い投稿・古いルームは自動で削除
- **XSS 対策**：投稿は生データで保存し、画面では `textContent` で表示
- **DoS 対策**：リクエスト・本文・合言葉のサイズ制限、連投ロック、ルーム数の上限
- 制限値はすべて **2のべき乗**で統一

## 動作環境

- PHP 8.3 以上
- OS の一時ディレクトリ（`sys_get_temp_dir()`）に書き込めること
- `flock` が使えるローカルのファイルシステム

## 設置

`bbs.php` を PHP が動く Web サーバーに置き、ブラウザで開くだけです。

手元で試す場合は、PHP の組み込みサーバーが使えます。

```bash
php -S localhost:8000
# ブラウザで http://localhost:8000/bbs.php を開く
```

## 使い方

### 合言葉で入室する

1. トップ画面で「合言葉」を入力します（4〜64バイト）。同じ合言葉を入力した人が、同じ掲示板に入ります。
2. 「Web表示件数」を選んで入室します。
3. 掲示板画面で、「名前」を入力して本文を書き込みます。名前を省略すると「名無し」になります。

合言葉の長さは、文字数ではなくバイト数で数えます（ASCII は1文字1バイト、日本語は1文字3バイト）。前後の空白は取り除かれます。

入室すると、合言葉はサーバーで MD5 に変換され、`bbs.php?room=<MD5>` の URL に移動します。合言葉そのものは、フォームの POST 本文でだけ送られ、URL や履歴には残りません。

### URL で部屋に直接入る

`room` に合言葉の MD5（32桁の16進数）を指定すると、トップ画面を通らずに、その部屋に直接入れます。

| パラメータ | 内容 | 省略したとき |
|---|---|---|
| `room` | 合言葉の MD5（32桁の16進数。大文字・小文字どちらも可） | トップ画面を表示 |
| `name` | 投稿フォームの「名前」欄の初期値 | 空欄（投稿すると「名無し」） |
| `limit` | 表示件数 | 16 |

```
bbs.php?room=1a07b707111216c013badf260e14973b&name=taro&limit=32
```

合言葉の MD5 は、たとえば次のように求められます。

```bash
printf '%s' '合言葉' | md5sum
```

名前を入力して投稿すると、その名前が URL の `name=` に反映されます。そのため、ブラウザで「更新」しても、名前欄は同じ名前のままです。名前を空にして投稿すると、`name=` は URL から取り除かれます。

### 退室と更新

画面に「退室」「更新」ボタンはありません。ブラウザの機能を使います。

- **更新**: ブラウザの「更新」ボタンです。URL に部屋が入っているので、同じ部屋が開き、最新の投稿を取得します。
- **退室**: ブラウザの「戻る」ボタンです。トップ画面に戻ります。

## 制限値

サーバー側は `bbs.php` 冒頭の定数で設定します。名前・本文の長さと連投ロックは、クライアント側（`<script>` 内の定数）でも事前チェックに同じ値を使っています。

| 項目 | 値 | 定数 |
|---|---|---|
| 合言葉の長さ（入室フォームで判定） | 4〜64バイト（2^2〜2^6） | `ROOM_MIN_BYTES` / `ROOM_MAX_BYTES` |
| 名前の長さ | 最大64バイト（2^6） | `NAME_MAX_BYTES` |
| 本文の長さ | 最大1,024バイト（2^10） | `POST_MAX_BYTES` |
| リクエスト全体 | 最大4,096バイト（2^12） | `REQ_MAX_BYTES` |
| 1ルームの保持件数 | 最大1,024件（2^10） | `MAX_POSTS` |
| ルーム数 | 最大256（2^8） | `MAX_ROOMS` |
| 投稿・ルームの生存時間 | 1,048,576秒（2^20、約12.1日） | `MAX_AGE_SEC` |
| 連投ロック | 4秒（2^2）／同一IP・同一ルーム | `COOLDOWN_SEC` |
| 取得件数 | 初期16件（2^4）、上限1,024件 | `DEFAULT_LIMIT` / `MAX_POSTS` |

名前・本文の長さと連投ロックを変えるときは、PHP 側と JavaScript 側の両方を同じ値に揃えてください。揃っていないと、クライアントの事前チェックとサーバーの判定がずれます。

## API

画面は、次の API を呼び出して動いています。レスポンスはすべて JSON です。`room` には、合言葉そのものではなく、合言葉の MD5（32桁の16進数）を指定します。

### 投稿の取得

```
GET bbs.php?action=read&room=<MD5>&limit=<件数>
```

新しいものが後ろに並ぶ配列を返します。

```json
[{"name":"名無し","content":"こんにちは","time":"2026/11/14 12:34:56"}]
```

### 投稿の送信

```
POST bbs.php?action=send&room=<MD5>&limit=<件数>
Content-Type: application/json

{"name":"名無し","content":"こんにちは"}
```

`name` が空のときは、「名無し」になります。成功すると、投稿後の最新の一覧を返します。

```json
{"success":true,"posts":[{"name":"名無し","content":"こんにちは","time":"2026/11/14 12:34:56"}]}
```

### エラー

エラー時は `{"error":"メッセージ"}` を返します。

| HTTP | 主な原因 |
|---|---|
| 400 | アクション・`room`（MD5 の形式）・リクエスト形式の不正、本文が空 |
| 405 | `send` を POST 以外で呼び出した |
| 413 | リクエスト・本文・名前のサイズ超過 |
| 429 | 連投ロック中 |
| 500 | サーバー内部エラー（保存先を開けないなど） |
| 503 | ルーム数が上限に達していて、新しいルームを作れない |

### curl の例

```bash
ROOM=$(printf '%s' 'my-secret-room' | md5sum | cut -d' ' -f1)

# 送信
curl -X POST "http://localhost:8000/bbs.php?action=send&room=$ROOM" \
  -d '{"name":"taro","content":"hello"}'

# 取得
curl "http://localhost:8000/bbs.php?action=read&room=$ROOM&limit=16"
```

## データの保存

- 保存先：`sys_get_temp_dir()/bbs_<合言葉のMD5>`（ファイル権限は `0600`）
- 形式：投稿の配列を JSON で保存（日本語は `\uXXXX` にせず、そのまま保存）
- 投稿は生データで保存します。HTML エスケープは画面側で行うのではなく、`textContent` で表示することで防いでいます。

古い投稿とルームは、次のように削除されます。

- `read` はファイルを書き換えません。期限切れの投稿は表示しないだけです。
- 期限切れの投稿は、次の `send` のときにファイルから取り除かれます。
- 最終更新から約12.1日を過ぎたルームのファイルは、新しいルームの作成時と、送信32回に1回の割合で削除されます。

## セキュリティ設計と注意点

- **認証はありません。** 部屋の MD5 が鍵の代わりです。合言葉、または `room=<MD5>` の URL を知っている人は、誰でも読み書きできます。リンクの共有は、鍵の共有と同じです。
- **合言葉の MD5 化は、ファイル名と URL を一意にして生の合言葉を隠すためのものです。** 暗号学的な秘匿ではありません。MD5 は高速なので、短い合言葉は、ファイル名や URL の MD5 から総当たりで推測される可能性があります。「覗かれる可能性がある」ことは、仕様として許容しています。推測されにくい長めの合言葉を使ってください。
- **投稿は暗号化されません。** サーバーの一時ディレクトリに平文で保存されます。機密情報の送受信には使わないでください。
- **合言葉そのものは、入室フォームの POST 本文でだけ送られます。** URL・履歴・アクセスログには残りません。一方、MD5 は、ページの URL（`?room=`）、API 呼び出し、ブラウザの履歴、Web サーバーのアクセスログに残ります。
- **連投ロックは、IP アドレスで判定します。** IP は、ルームのハッシュと混ぜた8文字の短縮ハッシュとして保存します。リバースプロキシの背後では、全員が同じ IP に見えるため、全員が同じロックを共有してしまいます。その場合は、実 IP を取得する処理の追加が必要です。
- **ルーム数の上限（256）を使い切られると、新しいルームを作れなくなります。** 既存のルームは使い続けられます。`room` に任意の32桁の16進数を指定して投稿すれば部屋を作れるため、意図的に埋めることも可能です。約12日で期限切れになるのを待つか、一時ディレクトリの `bbs_*` ファイルを削除すると回復します。対策が必要な場合は、Web サーバー側のリクエスト制限（nginx の `limit_req` など）を併用してください。
- **ディスク使用量の上限は、最悪のケースで約300MB 程度です**（256ルーム × 1,024件 × 1件あたり約1.2KB）。
- **一時ディレクトリの扱いは環境によります。** OS やホスティング環境が一時ファイルを定期的に削除する場合、投稿が早く消えることがあります。
- 複数台のサーバーで負荷分散する構成には向きません（保存先が各サーバーのローカルな一時ディレクトリのため）。
